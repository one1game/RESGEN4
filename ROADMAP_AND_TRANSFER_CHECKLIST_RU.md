# Roadmap и чек-лист передачи

## Roadmap

### Подготовка релиза

Завершить аудит local/cloud adapter, убрать неоднозначные внешние fallback-вызовы, добавить формальные LICENSE и NOTICE, проверить лицензии сторонних ассетов и выполнить установку на чистой машине.

### Публичная beta

Опубликовать стабильную браузерную сборку, записать двухминутный gameplay walkthrough, добавить документацию по privacy и ошибкам и пригласить небольшую группу внешних тестеров.

### Проверка удержания

Измерять завершение первой сессии, возврат на следующий день, возврат через семь дней, среднюю длину сессии, распределение выбора операций, процент неудачных операций и частоту достижения resource cap. Баланс нужно менять по данным реальных игроков, а не только по симуляции.

### Расширение production

Добавить более богатые цепочки инцидентов, редкие варианты blueprint, динамические фракционные события, больше типов NPC-конвоев, более глубокие различия циклов и hosted backend только при реальной необходимости live multiplayer.

## Чек-лист передачи

- [ ] Подтвердить, что продавец владеет или может передать название, код, дизайн, тексты, музыку, шрифты и изображения.
- [ ] Добавить лицензию проекта или подписать отдельную передачу IP.
- [ ] Проверить лицензии всех зависимостей и сторонних ассетов.
- [ ] Удалить личные аккаунты, credentials, токены, локальные базы и browser data.
- [ ] Отозвать и заменить секреты, которые могли попасть в историю разработки.
- [ ] Проверить сборку чистого архива на новой машине.
- [ ] Чётко определить: лицензия исходников, эксклюзивная лицензия или полная передача IP.
- [ ] Зафиксировать период поддержки, обязательства по исправлениям и исключения.
- [ ] Использовать escrow или защищённую оплату до передачи исключительных прав.
- [ ] Передать репозиторий только после выполнения условий оплаты.

## Приёмочный тест покупателя

Покупатель должен установить зависимости, выполнить `npm run check`, запустить локальный сервер, создать новую SQLite-базу и проверить core loop, save/export, операции, флот, карту и 1000-hour retention harness. Затем нужно решить, остаётся ли Supabase-compatible adapter локальной API-абстракцией или заменяется hosted adapter.
