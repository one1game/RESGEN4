# CoreBox 5.0 — Demo for Developers & Buyers

Презентационная страница готовой коммерческой игры **CoreBox 5.0** (Cyberpunk Incremental)
с встроенным играбельным демо.

Сайт: https://one1game.github.io/RESGEN4/

## Что на сайте
- Маркетинговое описание продукта, техстек, состав поставки, условия лицензии.
- **Играбельное демо** в секции «Попробовать прямо сейчас» (подпапка `play/`).

## Демо-сборка (`play/`)
Статическая сборка для GitHub Pages, безопасная для продавца:
- **WASM-ядро (Rust)** с жёстко вшитым демо-лимитом — **3 пережитые ночи**, дальше блокировка добычи и прокачки.
- Прогресс — в `localStorage` браузера, без сервера и аккаунта.
- Клиентский JS минифицирован, контент урезан (первые 5 заданий, эндгейм-набор вырезан).
- Исходники Rust, полный баланс, сервер и БД-схема в публичный доступ не входят — передаются покупателю приватно.

## Для покупателей
Полный коммерческий пакет (исходники ядра, клиент, сервер, БД, документация, права) — по договору,
приватно. Публичный репозиторий содержит только демо-страницу и играбельную демо-сборку.
