# CoreBox 5.0 — Demo for Developers & Buyers

Презентационная демо-страница готовой коммерческой игры **CoreBox 5.0** (Cyberpunk Incremental).

Сайт: https://one1game.github.io/RESGEN4/

## Для кого
Для разработчиков и покупателей, которые рассматривают приобретение полного коммерческого пакета:
- готовая игра: Rust/WASM-ядро симуляции + клиент на HTML5/JS (25 модулей);
- полный состав исходников в поставке;
- права на коммерческое использование и монетизацию.

## Важно
Играбельная полная версия, ядро, схема БД и документация **не выкладываются публично** — передаются покупателю приватно по договору.

Публичный репозиторий содержит только маркетинговое демо (одностраничник `index.html`).
